A first-person escape room with no assets. Every texture, every sound and every object in it is generated in code — nothing is downloaded, and the whole game is one HTML file.

Play in your browser

Mouse and keyboard
W A S D move mouse look click examine G stow Tab notes

Tablet or phone — it switches by itself, no setting to find
left thumb move right thumb look tap examine bottom row what you are holding

Put it on your home screen. It installs as an app and works with no connection once you have played it once.

iPad — open this in Safari (not Chrome; only Safari can install on iPadOS), tap Share, then Add to Home Screen.
Kindle Fire — open this in Silk, then menu → Add to Home screen. It runs full-screen with no browser bars.
Android — Chrome offers Install app in the menu.

Prefer a file? The same game is one self-contained HTML document — save it and open it from anywhere, offline, no install and no server.
