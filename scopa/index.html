Install it on your device

No store, no account. The demo is a Progressive Web App — open it in your browser and add it to the home screen. It runs full-screen and works offline after the first load.

Open the game, then install ↓

iPhone & iPad

Open in Safari → tap Share ⬆︎ → Add to Home Screen → Add. Launch from the gold “7” icon.

Android

Open in Chrome → tap ⋮ menu → Install app / Add to Home screen → Install.

Kindle Fire

Open in Silk → menu → Add to Home screen. (For a native app, an .apk sideload build is coming next.)

PC & Mac

Open in Edge or Chrome → click the install icon ⊕ in the address bar → Install. Opens in its own window.
